## ✨ Features

- **🎨 Modern Dark & Glassmorphism Aesthetic:** Premium cyber-gradient styling, smooth transitions, and glowing accent highlights.
- **📱 Fully Responsive:** Adaptive layout optimized for mobile screens, tablets, and high-resolution desktop displays.
- **📂 Interactive Projects Showcase:**
  - Multi-category filtering (**All**, **Web**, **Mobile**, **Full Stack**).
  - Direct links to GitHub repositories and live deployments.
- **📊 Dynamic Skills Section:** Animated skill cards categorized by *Languages*, *Web Technologies*, and *Tools & Frameworks*.
- **🎓 Education Timeline:** Interactive cards illustrating academic history, grades, and focus areas.
- **📄 Downloadable Resume:** Direct access to download the latest professional resume PDF.
- **📬 Contact Integration:** Quick-connect contact form, email link, and social profiles.

## 💻 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bharathkumar2705/myPortfolio.git
   cd myPortfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
